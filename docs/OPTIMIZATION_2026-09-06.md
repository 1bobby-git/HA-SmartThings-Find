# HA-SmartThings-Find 1.4.3 — 최적화

2026-09-06 / Home Assistant 통합 패치

## 변경 내용

- 계정별 쿠키 저장 직렬화: 동시 호출의 중복 디스크 쓰기·오래된 스냅샷 덮어쓰기 방지
- 세션 파일 삭제 전에 진행 중인 저장 완료 대기
- 서버가 삭제한 쿠키를 부활시키지 않으며 인증·재로그인·물리 명령 재시도 정책은 유지

## 호환성과 범위

도메인, 기존 설정, 엔티티·장치 식별자와 공개 서비스 이름은 유지합니다. 의존성 일괄 업그레이드와 서버 측 세션 만료 우회는 포함하지 않습니다. SmartThings 브리지 앱과 ANCS 펌웨어는 변경하지 않습니다.

## 검증 범위

원본 전체 파일 해시를 확인한 뒤 기존 저장소 테스트를 변경 전후 실행합니다. HACS/Hassfest와 저장소별 CI 검증을 통과한 경우에만 릴리스를 게시합니다. 앞선 후보 묶음의 오프라인 테스트 103개와 실제 저장소 테스트 결과는 별개입니다. 운영 HA의 실제 로그인·쿠키 수명·재생·실기기 제어·장시간 운용은 검증하지 않았습니다. 테스트 통과만으로 모든 환경에서 무영향이나 성능 향상을 보장하지 않습니다.
